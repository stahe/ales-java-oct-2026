    Este documento es un producto de la IA Claude de Anthropic. Es la adaptación a Java del curso “Aprender C# 14 con .NET 10” (octubre de 2026), que a su vez es una reescritura del curso “Aprendizaje del lenguaje C# versión 3.0 con .NET 3.5 escrito por Serge Tahé en mayo de 2008. Conserva el esquema, los ejemplos y el hilo conductor del curso, y los reescribe en Java moderno:

    • el documento usa Java 25 (septiembre de 2025), la última versión de soporte a largo plazo de Java (LTS), y presenta, a lo largo de los capítulos, las novedades del lenguaje, desde los archivos fuente compactos de Java 25 hasta los hilos virtuales de Java 21, pasando por los records, las clases selladas y la coincidencia de patrones;
    • donde los dos lenguajes difieren, el documento hace algo más que traducir: las propiedades, las estructuras, la sobrecarga de operadores y los delegados de C# no existen en Java, que tiene sus propias soluciones (getters, records, interfaces funcionales); a la inversa, Java tiene conceptos que le son propios, como las excepciones verificadas y los hilos virtuales, y se presentan en detalle;
    • Dos capítulos tienen un enfoque distinto: la programación asíncrona, que Java resuelve con las clases [CompletableFuture] y los hilos virtuales en lugar de las palabras clave [async] / [await] , y el mapeo objeto-relacional, proporcionado por Hibernate, el ORM más utilizado en el mundo Java;
    • las bibliotecas son las que se usan actualmente en Java: [JUnit 6] para las pruebas, [Spring Framework 7] para la inyección de dependencias, [Jackson 3] para JSON, el controlador [MySQL Connector/J] para JDBC, [Hibernate 7] y [Spring Boot 4] para los servicios web; los proyectos se construyen con [Maven].

    Este documento no es un curso exhaustivo. Como los cursos de los que deriva, está dirigido a personas que ya saben programar y desean aprender los fundamentos de Java. Utiliza ejemplos: más de doscientos programas (más de trescientos archivos Java), la mayoría cortos, con comentarios línea por línea.

    1.1. Java de 1995 a 2026

    Sun Microsystems lanzó Java en mayo de 1995. Se basa en una idea que ha sido clave para su éxito: el compilador [javac] no produce código máquina sino un código intermedio, el bytecode, almacenado en archivos [.class], que la máquina virtual de Java (la JVM, “Java Virtual Machine”) ejecuta compilándolo sobre la marcha a código máquina. Un mismo programa compilado puede así ejecutarse en Windows, Linux o macOS: “escribe una vez, ejecuta en cualquier lugar”. Los lenguajes Kotlin, Scala y Groovy también producen bytecode y usan las mismas bibliotecas.

    Hitos principales:

    • 2006–2007: OpenJDK. Sun publicó el código fuente de Java con una licencia de código abierto (JDK). Todas las distribuciones actuales de Java se construyen a partir de OpenJDK;
    • 2010: Oracle adquiere Sun y se convierte en el principal contribuyente de Java;
    • 2014: Java 8, una versión decisiva: expresiones lambda, API Stream, nueva API de fecha y hora. Muchos programas en producción siguen escritos con este estilo;
    • Desde 2017 (Java 9): se publica una nueva versión de Java cada seis meses, en marzo y septiembre. Algunas versiones tienen soporte a largo plazo (LTS, “Long-Term Support”): Java 11 (2018), 17 (2021), 21 (2023) y 25 (septiembre de 2025), que es la que se usa en este documento; a partir de Java 17, se publica una nueva versión LTS cada dos años. Las demás versiones tienen soporte solo durante seis meses; las nuevas características suelen aparecer primero como “previews” (versiones preliminares) antes de ser finalizadas en una versión posterior;
    • El JDK es distribuido por varios proveedores, todos basados en OpenJDK y equivalentes para nuestros fines: Oracle, la Fundación Eclipse (Eclipse Temurin, proyecto Adoptium), Microsoft, Amazon (Corretto) y las distribuciones de Linux.

    1.2. Contenido del documento

    El documento incluye los siguientes capítulos:

    • Capítulo 2: Configuración del entorno de desarrollo (JDK 25, IntelliJ IDEA o VS Code, Maven, los comandos [java] y [javac] );
    • Capítulo 3: Fundamentos del lenguaje (tipos, operadores, estructuras de control, excepciones verificadas y no verificadas, enumeraciones, paso de parámetros);
    • Capítulo 4: Clases, records, interfaces, herencia, clases selladas, genéricos, paquetes, coincidencia de patrones;
    • Capítulo 5: Clases de Java de uso común: cadenas, arreglos, colecciones, API Stream, archivos de texto y binarios, JSON con Jackson, expresiones regulares;
    • Capítulo 6: Arquitecturas por capas, pruebas unitarias con JUnit 6 e inyección de dependencias con Spring;
    • Capítulo 7: Interfaces funcionales, expresiones lambda y eventos;
    • Capítulo 8: Hilos de ejecución, sincronización e hilos virtuales;
    • Capítulo 9: Programación asíncrona con [CompletableFuture] e hilos virtuales;
    • Capítulo 10: Acceso a bases de datos con JDBC;
    • Capítulo 11: Hibernate;
    • Capítulo 12: Programación web (TCP/IP, clientes y servidores TCP, HTTP con [HttpClient]);
    • Capítulo 13: Servicios web con Spring Boot;
    • Capítulo 14: Para ir más lejos;
    • Apéndices: Instalación de Laragon y MySQL, las dependencias de Maven utilizadas.

    1.3. El hilo conductor: el cálculo del impuesto

    El mismo problema se retoma a lo largo de todo el documento: calcular el impuesto sobre la renta de un contribuyente que solo tiene que declarar su salario. El tramo impositivo utilizado es el original (ingresos de 2003): ya no está vigente, pero basta para nuestro propósito, que es escribir la misma aplicación de varias maneras distintas. Se implementa en nueve versiones:

    3

    3
    5
    datos de cálculo leídos desde un archivo de texto o un archivo JSON

    A partir de la versión 5, las versiones siguientes reutilizan las capas de la versión 5 y reemplazan solo la capa que cambia: ese es todo el sentido de la arquitectura por capas presentada en el capítulo 6.

    Los programas pequeños son archivos fuente compactos: un único archivo llamado [.java], que se ejecuta con el comando [java File.java] (capítulo 2). Los programas de varios archivos que usan solo las bibliotecas del JDK se inician de la misma manera. Los programas que requieren una biblioteca externa (Jackson, JUnit, Spring, el controlador de MySQL, Hibernate, Spring Boot) son proyectos Maven ([pom.xml]).

    Todos los programas de este documento se compilaron sin errores ni advertencias con el compilador [javac] del JDK 25, usando la opción [-Xlint:all] que activa todas las advertencias, y se ejecutaron con las versiones de las bibliotecas indicadas en el apéndice. Los resultados reproducidos en este documento son los de esas ejecuciones. Los de los capítulos 2 a 4 se obtuvieron con la configuración de idioma y país franceses (fr-FR), como en un sistema Windows en francés: los números de punto flotante con formato se muestran con coma decimal y las fechas están en francés; los capítulos siguientes se ejecutaron con configuración en inglés (punto decimal, fechas en inglés). Dos notas:

    • los mensajes de error del JDK (mensajes de excepciones, mensajes del compilador) están en inglés: el JDK no ofrece traducción al francés para ellos;
    • los ejemplos se ejecutaron en Linux. En su mayor parte, esto no hace diferencia: Java es multiplataforma. Las pocas diferencias (rutas de archivos con / en lugar de \, comandos de terminal) se señalan donde aparecen.

    Los resultados de los programas con múltiples hilos, asíncronos o de red, así como los tiempos de ejecución medidos, pueden variar de una ejecución a otra: los comentarios se centran en lo que es reproducible.
