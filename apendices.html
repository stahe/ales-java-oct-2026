    15. Apéndices

    15.1. El SGBD MySQL con Laragon

    Los capítulos 10 y 11 de este documento usan el SGBD MySQL 8. La forma más sencilla de instalarlo en Windows es instalar Laragon, un entorno de desarrollo portátil que incluye MySQL, el cliente gráfico HeidiSQL, una terminal configurada, Apache y PHP. El autor también lo usa para sus cursos de PHP.

    15.1.1. Instalación

    Laragon puede descargarse desde https://laragon.org. El proceso de instalación es estándar; puede conservar la carpeta de instalación sugerida ([C:\laragon]). Laragon proporciona MySQL 8 (la versión exacta depende de la versión de Laragon), con una cuenta de administrador [root] que no tiene contraseña y un servidor que escucha en el puerto 3306 de la máquina local. Esta es la configuración que suponen los ejemplos del documento, donde las URL JDBC tienen la forma:

    1
    jdbc:mysql://localhost:3306/dbarticles

    con el nombre de usuario [root] y una contraseña vacía. Si MySQL se instaló de otra manera, con una contraseña para [root], deberá actualizar los ejemplos en consecuencia (archivos [.properties] o constantes al inicio de los programas).

    En un sistema sin Laragon, también puede instalar MySQL Community Server desde https://dev.mysql.com/downloads/mysql/, o su derivado de código abierto, MariaDB. Sin embargo, los ejemplos solo se han probado con MySQL 8: los scripts del Capítulo 10 usan una collation específica de MySQL 8 ([utf8mb4_0900_ai_ci]), y con MariaDB habría que adaptarla, al igual que el controlador JDBC (MariaDB ofrece el suyo).

    15.1.2. Inicio y detención de MySQL

    La ventana principal de Laragon incluye un botón “Start All” que inicia los servidores (Apache y MySQL) y un botón “Stop” que los detiene. MySQL no es un servicio de Windows que se ejecute al arrancar el sistema: solo se ejecuta cuando se inicia desde Laragon, lo que evita que consuma recursos cuando no se utiliza. El menú de Laragon (clic derecho en la ventana) también permite iniciar solo MySQL y seleccionar su versión.

    Cuando MySQL no está en ejecución, los programas de los Capítulos 10 y 11 fallan con una excepción del controlador JDBC que indica que no se pudo establecer una conexión ([CommunicationsException]: “Communications link failure”): esto es lo primero que se debe verificar en caso de error.

    15.1.3. El cliente de línea de comandos

    El botón Terminal de Laragon abre una terminal donde están disponibles los comandos de Laragon, incluido el cliente de línea de comandos de MySQL ([mysql]). Para conectarse al servidor, use:

    1
    > mysql -u root

    luego ingrese comandos SQL terminados con punto y coma ([show databases;], [use dbarticles;], [select * from articles;]) y [exit] para salir. El cliente también puede ejecutar un script SQL, que es lo que hace el Capítulo 10 para crear sus bases de datos:

    1
2
3
    > cd java-oct-2026\10-jdbc\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbtaxes.sql

    Los scripts recrean por completo su base de datos cada vez que se ejecutan: puede volver a ejecutarlos para restaurar los datos a su estado inicial después de las pruebas.

    15.1.4. El cliente gráfico HeidiSQL

    El botón Database de Laragon inicia el cliente gráfico HeidiSQL. En el primer inicio, HeidiSQL ofrece una sesión de conexión ya configurada para el servidor MySQL de Laragon (host [127.0.0.1], usuario [root], contraseña vacía, puerto 3306); basta con abrirla. Verá:

    • a la izquierda, la vista de árbol de las bases de datos del servidor y sus tablas;
    • a la derecha, pestañas que muestran la estructura de una tabla, sus datos (que se pueden editar directamente) y un campo para ingresar consultas SQL (la pestaña “Query”), que se ejecutan con [F9].

    Para crear una base de datos mediante un script del Capítulo 10, abra el script (desde el menú “File”, con el comando para cargar un archivo SQL) en una pestaña de consulta y luego ejecútelo ([F9]). También puede crear una base de datos, un usuario y los permisos de usuario mediante los menús de HeidiSQL (clic derecho en la conexión / “Create New” / "Database"; menú "Tools" / "User Manager"), pero los scripts SQL tienen la ventaja de ser reproducibles y poder volver a ejecutarse.

    Los IDE también pueden conectarse a una base de datos: IntelliJ IDEA mediante su ventana “Database”, VS Code mediante una extensión como “SQLTools” o “MySQL”.

    Una vez concluidas las pruebas, se puede eliminar una base de datos con el comando SQL [drop database name;], en el cliente [mysql] o en HeidiSQL.
